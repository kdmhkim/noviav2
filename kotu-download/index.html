Seven modules, one window

  • Image

    jpg png gif webp bmp tif ico psd

    Arrow keys walk the folder, the wheel zooms from 10% to 800%, and EXIF rotation is applied automatically.

  • Video

    Plays through the bundled libvlc engine and remembers where you stopped. Folder playback and repeat modes are included.

  • Audio

    Picks up where you left off, the same way video does, with folder playback and repeat modes.

  • Document

    Markdown and HTML render to a reading view, and text files keep their encoding when you save them.

  • Archive

    zip 7z rar tar

    Archives open in place, and you can open a single file straight out of one without extracting it first.

  • All Readable

    Everything else KOTU recognizes opens in the same window, so there is no hunting for the right application.

  • Hardware Monitor

    CPU and GPU temperatures, load, clocks, RAM, fans and drive temperatures on live graphs. Pin one sensor to the tray icon.

What you need

  • Windows 10 version 1809 or newer, or Windows 11. 64-bit (x64) only.
  • No codec pack. The extraction and playback engines ship inside the app — 7-Zip and libvlc are bundled — so it plays and extracts the moment you install it.
